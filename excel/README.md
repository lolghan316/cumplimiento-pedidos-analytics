# Conciliación Excel

Conciliacion_Pedidos_v1.xlsx conserva el libro entregado.
Diez pedidos, dos por estado, comparan cantidad entregada, pendiente, estado y OTIF.
Las fórmulas utilizan las líneas y eventos importados; no es una segunda fuente externa.
consultas_power_query.m contiene las consultas extraídas del libro para lectura y revisión.
Las diez comparaciones guardadas son COINCIDE. No se recalculó el archivo con Excel en la revisión remota.
